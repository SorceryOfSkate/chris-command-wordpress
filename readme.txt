Public WordPress foundation for approved Chris Command modules.

== Description ==

Version 0.1.0 is an intentionally inert foundation. It establishes a secure plugin structure and release process without exposing or migrating private dashboard modules or data.

== Installation ==

1. Download the versioned release ZIP.
2. In WordPress, open Plugins > Add New > Upload Plugin.
3. Upload the ZIP and activate Chris Command.
